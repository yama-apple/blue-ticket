# 青切符バスター 🚲

自転車の青切符制度（交通反則通告制度）を楽しく学べる教育ゲームアプリ（PWA）

## アプリの目的

2025年4月に施行された自転車の交通反則通告制度（いわゆる青切符）について、ゲーム感覚で漏れなく学習できるアプリです。

丸暗記ではなく、実際の道路状況をシミュレーションした場面判断型の出題で「なぜ危険なのか」を理解しながら学べます。

## 想定ユーザー

- 自転車に日常的に乗る16歳以上の方
- 青切符制度について正しく理解したい方
- 「なんとなく知っている」を「正確に理解している」に変えたい方
- 通勤・通学で自転車を使う方

## なぜPWAなのか

- **App Storeの審査不要**: すぐに公開・更新可能
- **インストール不要**: Safari でアクセスしてホーム画面に追加するだけ
- **オフライン対応**: Service Worker で一度読み込んだデータはオフラインで使用可能
- **軽量**: ネイティブアプリに比べてストレージ消費が少ない
- **クロスプラットフォーム**: iPhone Safari を最適化しつつ、他のブラウザでも動作

## なぜゲーム化したのか

- 法制度の学習は退屈になりがちだが、ゲームループにより継続学習のモチベーションを維持
- SRS（間隔反復学習）により効率的な記憶定着を実現
- 進捗の可視化（ランク・バッジ・図鑑）で達成感を提供
- 苦手克服モードで弱点を的確にカバー

## 技術スタック

| 技術 | 理由 |
|------|------|
| **Vite** | 高速なビルド・HMR で開発効率が高い |
| **React + TypeScript** | 型安全なコンポーネント設計 |
| **Tailwind CSS v4** | ユーティリティファーストで iPhone 向け UI を素早く構築 |
| **Zustand** | 軽量で React に最適な状態管理。ボイラープレートが少ない |
| **vite-plugin-pwa** | PWA 対応（Service Worker、Manifest）をワンストップで提供 |
| **Vitest** | Vite ネイティブなテストランナー |

### なぜ Next.js ではなく Vite + React か

- 本アプリはフロントエンドのみで完結するため、SSR/SSG は不要
- Vite のほうがビルドが速く、PWA プラグインとの統合もスムーズ
- 静的ホスティング（GitHub Pages, Cloudflare Pages）に最適

## データ構造

学習コンテンツはすべて JSON ファイルで管理され、コード改修なしで差し替え可能です。

| ファイル | 内容 |
|----------|------|
| `rules_overview.json` | 制度の概要 |
| `violations.json` | 違反類型（20+項目） |
| `scenarios.json` | シナリオ問題（100+問） |
| `glossary.json` | 用語集 |
| `faq.json` | よくある質問 |
| `version.json` | データバージョン・更新履歴 |

### violations.json の構造

各違反エントリには以下を含みます:
- `id`, `category`, `title`, `short_description`
- `legal_basis_optional` - 根拠法令
- `penalty_amount` - 反則金額
- `severity` - 危険度（low/medium/high/critical）
- `explanation`, `why_dangerous`, `common_misunderstanding`, `mnemonic`
- `tags`, `related_scenarios`

### scenarios.json の構造

各シナリオには以下を含みます:
- `id`, `title`, `scene_type`, `description`
- `choices[]` - 選択肢（4択）
- `correct_choice_id`, `explanation`
- `linked_violation_ids[]` - 関連する違反
- `difficulty` (1-4), `risk_level`

## データ更新方法

1. `src/data/` 配下の JSON ファイルを編集
2. `version.json` のバージョンと更新履歴を更新
3. ビルド & デプロイ

将来的には管理画面や CMS からの更新も可能な構造です。

## ゲームシステム

### デイリーチャレンジ
- 毎日5問のシナリオに挑戦
- 新規・復習・苦手のバランス配分
- クリアで XP とコインを獲得

### SRS（間隔反復学習）
- 各違反項目に5段階の習熟度
  - 未学習 → 学習中 → 要復習 → 定着 → 実戦的に理解
- 正答率・回答速度・連続正解を考慮
- 忘却曲線に基づいた復習タイミング

### ランクシステム
- 見習いライダー → ルール初心者卒業 → 交差点マスター → 夜間安全番長 → 青切符回避名人 → 自転車安全教官

### 違反図鑑
- ゲームを進めるほど図鑑が解放
- 各違反の詳細な解説・危険性・よくある誤解・覚え方を収録

## 注意事項

- **本アプリは学習用であり、法的助言を提供するものではありません**
- 最終的には必ず公式情報（警察庁・各都道府県警察の公開情報）をご確認ください
- 個別の取り締まり結果を保証するものではありません
- 制度改正により内容が変わる場合があります
- データ更新日はアプリ内の設定画面で確認できます
