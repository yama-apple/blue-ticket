# 今後の拡張案

## Phase 1: コンテンツ拡充
- シナリオ問題を200問以上に拡充
- イラスト/図解の追加（SVG or 画像）
- 場面を視覚的に表現するシーンイラスト
- 問題形式の追加（ドラッグ分類、反則金マッチング、危険箇所指摘）

## Phase 2: ゲーム性強化
- タイムアタックモード（瞬時判断型の出題）
- 連続ラウンド形式（ライフ制）
- カテゴリ別チャレンジ
- 実績システムの拡張
- コインで購入できるカスタマイズ要素

## Phase 3: 社会性
- 匿名リーダーボード
- 友人とのスコア共有（シェアカード画像生成）
- 週間ランキング

## Phase 4: コンテンツ管理
- 管理画面（CMS）の実装
- データのリモート更新チェック
- A/B テストによる問題文改善

## Phase 5: プラットフォーム拡張
- 多言語対応（在日外国人向け）
- 都道府県別ローカルルール補足
- 音声読み上げ対応
- 通知リマインダー
- Android PWA 最適化

## Phase 6: 分析・改善
- 学習データのエクスポート/インポート
- 学習効果の分析ダッシュボード
- 出題パターンの最適化（AI ベース）
- ユーザーフィードバック収集

## 技術的改善
- IndexedDB への移行（大量データ対応）
- Web Worker でのバックグラウンド処理
- プッシュ通知
- ウィジェット API 対応
