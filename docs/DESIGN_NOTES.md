# デザイン方針メモ

## コンセプト

「堅すぎる官公庁アプリ」ではなく、交通教育ゲームとして親しみやすいが、内容は軽薄にしないデザイン。

## カラーパレット

- **Primary (Blue)**: #2563eb 系 — 信頼感・制度の正式感を表現
- **Success (Green)**: #22c55e 系 — 正解・安全の表現
- **Danger (Red)**: #ef4444 系 — 不正解・危険の表現
- **Warning (Yellow)**: #f59e0b 系 — 注意・要復習
- **Accent (Purple)**: #a855f7 系 — 達成・特別感

## タイポグラフィ

- システムフォント（-apple-system, Hiragino Sans）
- 本文: 14-16px
- 見出し: 18-24px
- 小テキスト: 10-12px

## iPhone最適化

- 縦持ち前提
- 片手親指で押しやすい大きめボタン（最低 44px タップ領域）
- Safe Area 対応（ノッチ・ホームバー）
- 下部ナビゲーション
- カード UI 中心で情報を区切る
- スクロールは垂直のみ

## コンポーネント方針

- Card: 角丸 16px、影付き、パディング 16px
- Button: 角丸 16px、最低高さ 48px
- Badge: 丸型、小さいテキスト、カラーコード
- ProgressBar: 角丸 full、アニメーション付き

## アクセシビリティ

- 色だけで正誤を伝えない（アイコン○✕、テキスト「正解」「不正解」を併用）
- 十分なコントラスト比
- タップ領域の確保

## アニメーション

- 控えめに（過剰にしない）
- 正解時: 短い bounce
- 報酬: トースト表示（2秒で消える）
- 画面遷移: 即座に切り替え（重いトランジションは不要）
